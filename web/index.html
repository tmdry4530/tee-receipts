    What is checked where

    • Browser: sha256 of the bytes, the signed text model:sha256(req):sha256(resp), EIP-191 ecrecover (vendored @noble/curves).
    • NEAR contract (view calls): verify_receipt, check_response_signature (the contract runs ecrecover itself), get_signer_history.
    • Not here: Intel TDX / NVIDIA attestation evidence is verified off-chain by the CLI before a signer is registered; the on-chain attestation hash lets anyone redo that from the saved report (fixtures/testnet/attestation-evidence.json).
    • This page sends nothing except read-only JSON-RPC query requests to the RPC above. Prompt and reply never leave your browser.
